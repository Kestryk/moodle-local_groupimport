# Guide step labels — K21-04

Student Management guided-card step labels inherit the existing guide-visuals
capsule (white 74%, 999px radius, inset border, 0.18rem / 0.44rem padding).
The Discovery mixin supplies numbering, typography and wrapping, without
removing that surface. The K19-02 text-only reset is scoped to the existing
`.easyedu-guide--mass-import` root, where it remains intentional.
Floating checklist items, commands and the Guide engine are unchanged.
No second capsule component or product-local override is introduced.
