# Changelog

This file lists notable product changes, with the newest changes first. Internal task identifiers and test-run notes are kept in maintainer records rather than release notes.

## Unreleased

### Student management

- Manage course participants, groups and groupings from responsive workspaces with search, filters, sorting, pagination, multi-selection and drag-and-drop.
- Use keyboard-accessible selection and actions, detailed entity views, and optional display preferences.
- Large lists render incrementally while preserving their full counts and selection scope.

### Mass Import

- Preview and edit CSV, XLS and XLSX rows before importing them.
- Match only users enrolled in the selected course, with administrator-enabled identifiers.
- Apply bounded file and row processing, respect course upload limits, and produce spreadsheet reports with formula-like values treated as text.
- Review and restore reversible import history, with privacy export, deletion and retention controls.

### Guidance and administration

- Follow localized, responsive guides for common participant and group tasks, with keyboard support and configurable animation levels.
- Configure the plugin through Moodle's native administration settings and controls.

## 0.3.0-beta — 2026-07-02

- Added the reusable EasyEdu interface foundation and an interactive, responsive EasyStud guide.
- Improved compact action menus, help bubbles and course-management layouts.

## 2026-06-30

- Introduced the simplified participant, group and grouping management interface.
- Added responsive selection, move and removal actions, detail dialogs and drag-and-drop.
- Improved Mass Import previews, file interpretation and import reports.

## 2026-06-15

- Began the EasyStud redesign and Moodle 4.5 compatibility work while retaining the plugin's existing data and URLs.
