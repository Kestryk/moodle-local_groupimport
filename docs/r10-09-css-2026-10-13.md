# R10-09 ? Result count height

The embedded Kit currently defines Select all min-height 1.62rem and a result
count with vertical padding 0.32rem. The late control-count typography can make
the latter taller. The component adapter uses the existing 1.62rem size for
both via one local custom property, centres the count and removes its vertical
padding. Count semantics, text, overflow and noninteractive role stay unchanged.

Sass and diff-check PASS. Cases 0/1/many/long FR/EN remain to measure natively.
This is a bounded consumer candidate, not canonical Kit/Foundations acceptance;
Codex1 must propagate the shared size after review. Generated CSS is external.
