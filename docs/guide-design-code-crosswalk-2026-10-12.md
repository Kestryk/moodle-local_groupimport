Working rules: check existing source geometry before inventing another variant;
prefer composing linked primitives in ordinary hosts; preserve accepted card
fingerprints. Record initial failed creation/measurement separately and reconcile
exact IDs after timeout. Stored stacking order is not visual flex order. Verify
actual text bounds and saved rich text; cached glyphs can lag their override.
Native metric reflow restores the original font immediately and is not a type
change. Treat1px catalogue glyph tolerance as distinct from container overflow.

Tests should emit only the first differing CSS excerpt, not megabytes of compiled
styles on assertion failure. Measure the actual native baseline before compact
layout adaptation, and preserve its immutable helper. Keep all media outside Git
with explicit manifests; no full-directory Kit/agent-doc import is needed for a
bounded canonical SCSS sync.
