## Drag diagnosis

Boost's smooth-root rule also exists in 5.1: it was not introduced by 5.3.
The observed 5.3 layout chooses the HTML scroller. A smooth `scrollTop` write
can leave the immediate read unchanged, so the old continuation check ends
the animation-frame loop. The next dragover starts it again in pulses.
An immediate write keeps that existing loop moving without changing normal
page scrolling, activation zone, velocity formula or drop behavior.

Native raw observations: predecessor down 690→833; candidate down 609→1048
and up 1657→1503, each with 23 dragover events. Starting positions differ;
these are interaction observations, not a controlled FPS/throughput benchmark.
An earlier harness accidentally blocked the read-only `movestatus` POST;
that failed predecessor is retained. The final harness permits this read and
records zero business writes and zero console errors.
