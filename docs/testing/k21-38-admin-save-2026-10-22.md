# Administration Save command — shared Kit adaptation

The native Moodle Save command previously inherited different font sizes and
responsive sizing from each supported theme/version. The plugin now applies the
existing Kit primary button and touch-target recipes to this command only.
The native form, submit handling, translations and keyboard focus rules remain.

The selector requires the plugin's administration body ID, native settings form,
final action row, offset wrapper and primary submit button. It cannot match Save
commands on another Moodle administration page. No core template or global `.btn`
rule changes. No new Kit definition is needed.

## Native checks

Chromium headless, Moodle 4.5 local HTTPS, actual administrator settings form,
English/French at 1600/390. The French command reads “Enregistrer les
modifications”; English reads “Save changes”. The compiled rules are applied
temporarily to the native document, then removed. No form is submitted.

Each label is contained, its centre hits the button and the native original
geometry is restored after removal. These match the eight earlier prototype
checks on Moodle 5.1/5.3. The negative control on Moodle's debugging settings has
zero selector matches and unchanged button geometry and paint.

The original strict whole-page no-overflow oracle is retained separately: the
4.5 installation already overflows horizontally by 464 px in EN and 520 px in FR
at 390. Both values remain identical with the new button rules; the button itself
fits. These are pre-existing page issues, not whole-page PASS results. Desktop
overflow is zero. This change does not certify unrelated page layout.

No JavaScript exception was observed. The installation separately reports missing
theme images (HTTP 404); no asset or theme configuration was changed here.

## Build boundary

Use the recorded Node 22.11.0 / Sass 1.79.1 toolchain and release page builder.
Only `styles/administration.css` changes. Removing the eight added, narrowly
scoped button rules leaves the previous Administration CSS unchanged. Student
Management, Mass Import, Guide and global CSS remain byte-identical.

The older `test-admin-typography-browser.js` fixture still loads the deliberately
empty global `styles.css`, rather than the Administration page sheet. It fails
on the browser's default 24 px heading versus an expected 20 px. The global sheet
is unchanged from the parent commit; this obsolete fixture is not fixed in this
button-only change and is not reported as a passing check.

The local test account's explicitly authorised administrator access is documented
in the workstation test-access procedure, outside the plugin repository. No
account credentials or deployment settings are part of this change.
