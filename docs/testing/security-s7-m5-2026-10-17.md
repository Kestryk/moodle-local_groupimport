## Contract

report_export::write_row writes all headers and all five report columns using
setCellValueExplicit(..., DataType::TYPE_STRING). Automatic numeric/formula
binding is removed from both paths in export.php. It preserves leading zeroes,
large numeric identifiers, date-like strings and literal HTML/text.

Before writing, prefix an apostrophe for = + - @, their fullwidth counterparts,
and leading tab/CR/LF, including formula prefixes after whitespace/BOM. Already
literal apostrophes are retained. Explicit type is the main XLSX protection;
the prefix is additional protection if values are copied into another tool.
This deliberately changes dangerous cell content to apostrophe-prefixed text,
so a reimport of such values retains that apostrophe rather than silently
restoring an executable-looking original. Normal text is unchanged.

The existing sheet title, status labels/colours, column widths, header typography,
filter, frozen pane, filename, MIME, login, capability and course-scoped history
lookup are retained. No product styles/templates/AMD or native visual changes.
Precalculation is disabled. Request-owned output temp files and worksheets are
cleaned in finally, including writer failures. No shared persistent temp folder.

Native report_exported is triggered only after workbook generation/read succeeds,
just before send_file. Its context/object/actor ids contain no row values,
identifier, filename or content. It records generation, not proof of a client
finishing its download. Unknown/invalid history and denied access emit no event.
