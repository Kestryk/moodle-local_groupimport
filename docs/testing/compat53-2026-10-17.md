## Nonvisual correction

Moodle5.3 secondary navigation uses React under secondarynav-tabbar, including mds-nav-pill links. The existing adapter ran only at startup/250ms/1000ms. It could miss a late replacement even where the legacy secondary-navigation wrapper stayed present. The adapter now watches only the stable secondary-navigation/secondarynav-tabbar hosts for child-list replacement and reuses its existing native-participant URL rewrite. It does not observe attributes or mutate any label/class/style. Nested hosts are not observed twice; unrelated card lists and the participant dropdown are not observed. A missing MutationObserver retains the old timers.

The same URL predicates preserve explicit native bypass and other courses. No import of React, MDS, a5.3-only API, new control or alternate navigation rendering. The server capability guards that load this module are unchanged.
