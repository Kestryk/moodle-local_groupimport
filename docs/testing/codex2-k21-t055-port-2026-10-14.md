# K21 port to the T055 group-card module

The dedicated branch starts at Claude70db3f96. Only the product function
`updateStructureSummary` in `amd/src/local/cm/group_cards.js` is changed;
its existing imported countLabel is reused. The two server-rendered counters
are updated from the on-demand model's complete group/grouping arrays.
An absent model or absent raw data returns without touching SSR counters.
The old single badge and rendered-DOM counting fallback are removed.

The existing Moodle toolchain rebuild changes only group_cards AMD/map.
No course_manager.js, local/sm source, stylesheet, language or PHP is changed.
Codex1 integrates this narrow port with the already served K21 markup and
local_groupimport_count_string/local_groupimport_count_template count forms.

The targeted test `tools/release/test-k21-summary-t055.cjs` evaluates the
actual exported function against real FR/EN PHP count-form fixtures and the
actual browser countLabel. Counts0/1/2/14/54 are tested with ready, null and
incomplete models (30 cases); deliberately wrong rendered-DOM cardinalities
cannot overwrite server values. PASS30, plus source-test/build syntax checks.
Generated evidence: `<workspace>/artifacts/es-k21-t055-summary-test.json` and
`es-k21-t055-summary-test-ready.log`. The first invocation only failed module
resolution in the fresh worktree; the successor resolves the existing
runtime Playwright toolchain through process-local NODE_PATH, restored after.

This is an N0 function migration. It does not claim a new native FR/EN
1280/390 visual pass, human acceptance, Penpot or Moodle4.5 acceptance.
The visual composition remains the two separate Groupings/Groups count
labels in Groups & groupings; no new visual element is introduced.
