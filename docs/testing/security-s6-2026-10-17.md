## Result and limits

The shared import_reader handles UTF-8 (optional BOM), BOM-marked UTF-16LE/BE,
and valid Windows-1252. Invalid encodings/control bytes fail closed. CSV uses
logical fgetcsv records with explicit empty escape (RFC doubled quotes), so
quoted newlines are not split into participants. Separator detection supports
semicolon, comma and tab. Invalid/unclosed quoting is rejected, not truncated.
Byte bounds apply before and after conversion. Row/column/cell bounds apply
before exposing a preview: 5 MiB, 5000 data rows, 64 columns, 50000 cells.

XLSX uses explicit Xlsx reader, never auto-detection of HTML/ODS/SYLK under an
Excel extension. Legacy Xls is used only if that native class actually exists.
Moodle's provided library on this workstation deliberately omits both legacy
Xls reader/writer. This pre-existing lack of support now has a localized
conversion message (CSV/XLSX), not a generic exception. Real XLS is NOT certified
by this delivery; no third-party dependencies were installed or copied.

Before XLSX reading, bound ZIP entries to 256, individual expanded size 10 MiB,
total expanded size 20 MiB; listWorksheetInfo bounds all sheets (max 16) and
aggregate row/column/cell dimensions. A read filter adds fail-closed cell bounds
if metadata underreports. Formulas are read as text, not calculated. Preserve
the native read-data-only worksheet selection, including its existing active
sheet behavior. Only the selected native active sheet becomes the import rows.
Temporary input uses make_request_directory and is unlinked in finally;
worksheets are disconnected on success/failure.

Filepicker and POST content size use min(plugin 5 MiB, effective Moodle/course
limit). Existing default visual copy, templates, SCSS and AMD remain unchanged.
B1/B2 server-session preview, edit transport, expiry/ownership and transaction
remain intact. The parser demonstrably retains 3000 rows; the separate existing
B2 synchronous confirmation ceiling is STILL 1000. Larger previews/confirmation
are rejected explicitly by the existing page rather than silently shortened.
This does not claim that an approved 3000-row database import is now enabled.
