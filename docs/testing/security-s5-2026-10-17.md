## Contract

Single, grouped and exceptional duplicate fallback import lookups now require the
course context. SQL joins get_enrolled_sql before matching email, username,
idnumber or enabled custom profile fields. Only user id is loaded for scoped
imports: passwords and unrelated account/profile columns are not fetched.
No unscoped retry is performed. Existing unscoped batch_reader callers preserve
their API/shape, and group/grouping batch lookups remain unchanged.

Unknown, outside-course, no-longer-enrolled and ambiguous inputs use the same
localized importuserunavailable message. Input identifiers may be echoed but no
resolved outside-course account details are exposed. Preview and confirmation
share the policy. Only these required error texts change; no visual assets,
templates, styles, AMD or reserved Claude modules are touched.

Replacement imports and historical restores call groups_remove_member_allowed
before removal, and abort on protected membership or failed native removal.
The existing B2 import_execution transaction already commits membership changes
and history together; retain it. Add explicit exception rollback to the existing
restore transaction. Core import_applied and import_rolled_back events are queued
inside those transactions and contain only native IDs/context, never input rows,
identifiers or file content. The restore event describes replaying the historical
target state, not undoing all native operations.
